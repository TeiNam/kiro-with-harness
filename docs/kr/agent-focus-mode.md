# 에이전트 포커스 모드와 하네스

Kiro IDE 1.0은 **에이전트 포커스 모드(Agent Focus Mode, 실험적)**를 추가했다 — 코드를 한 줄씩 편집하는 대신 에이전트를 지휘하는 채팅 우선 레이아웃이다. 이 가이드는 포커스 모드를 하네스 구조에 매핑한다.

> 출처: [Agent Focus Mode](https://kiro.dev/docs/experimental/focus-mode/), [What's new in IDE 1.0](https://kiro.dev/docs/whats-new-1-0/). 확인일 2026-07-14.

## 포커스 모드가 바꾸는 것

| | 에디터 뷰 | 에이전트 포커스 모드 |
|--|-----------|----------------------|
| 주 작업면 | 코드 에디터 | 채팅 |
| 파일 편집 | 직접 | 에이전트를 통해 |
| 세션 | 단일 포그라운드 | **다중 병렬** |
| 스펙 | 순차 단계 | 대화형 후 형식화 |

우측 상단 **Agent Focus** 버튼으로 토글한다. 세션은 두 뷰 간에 이어지며 동시 실행도 가능하다. 실험적 기능이라 인터페이스·동작이 바뀔 수 있다.

## 하네스가 포커스 모드에 맞는 이유

하네스는 이미 손수 편집이 아니라 *에이전트 지휘*를 중심으로 설계됐다:

- **역할 기반 에이전트 묶음**(리뷰어·build-resolver·`architect`·`deep-researcher`·`devops` 등) — 각 세션에서 목적에 맞는 에이전트를 에이전트 선택기에서 고른다.
- 모든 IDE 에이전트의 **tag-based tools**(`read`/`write`/`shell`/`web`) — 포커스 모드의 권한 프롬프트가 에이전트별로 깔끔히 해석된다(역할별 최소권한).
- 독립 작업을 병렬 DAG로 위임하는 **오케스트레이터**(`kiro-cli`, CLI 티어).

## workflow picker → 하네스 에이전트

포커스 모드의 새 세션 **workflow picker**(Spec / Plan / Bug Fix / Quick Spec)는 그 세션의 에이전트 모드를 정한다. 각각 하네스 에이전트와 짝지으면:

| 워크플로 | 역할 | 하네스 짝 |
|----------|------|-----------|
| **Spec** | 구조적 기능 개발 | `architect`(설계) → 구현 → `code-reviewer`/언어 리뷰어 |
| **Plan** | 변경 없이 계획 수립 | 큰 구조 결정은 `architect`, 내장 Plan Agent |
| **Bug Fix** | 조사 → 진단 → 해결 | 언어 `*-build-resolver`(빌드 실패) → `*-reviewer` |
| **Quick Spec** | 요구/설계/작업 자동 생성 | freeform으로 시작해 의도가 확정되면 스펙 첨부 |

## 병렬 세션: 층위가 다른 두 계층

포커스 모드의 **다중 병렬 세션**과 오케스트레이터의 **DAG 위임**은 보완적이지만 다른 층위에서 동작한다:

- **IDE 포커스 모드 병렬 세션** — 서로 다른 작업/워크스페이스를 다루는 여러 *최상위* 에이전트 세션. 왼쪽 패널에서 상태(spinning/warning/paused)로 모니터링.
- **CLI 오케스트레이터 DAG** — *하나의* `kiro-cli` 세션 안에서 독립 스테이지가 격리 서브에이전트로 팬아웃(`depends_on` 없는 스테이지 동시 실행) 후 수렴. [`AGENTS.md`](../../agents/AGENTS.md) 참조.

포커스 모드 세션은 *직접 감독하는 병렬 트랙*에, 오케스트레이터는 *한 트랙 내부의 병렬 하위작업*에 쓴다.

## 여전히 에디터/IDE 뷰가 필요한 것

포커스 모드는 일부 작업을 의도적으로 IDE 뷰로 되돌린다. 다음 하네스 접점이 거기 있다:

- **MCP 서버 관리** — 하네스가 `.kiro/settings/mcp.json`을 기록한다. 편집/점검은 IDE 뷰에서.
- **터미널 & 전체 git** — 설치기 실행(`node install.js …`), `--status`, 커밋.
- **직접 파일 편집 및 설정/환경설정**.

## 설치 참고

포커스 모드는 동일한 `.kiro/` 자산 위의 UI 계층이다 — 하네스 설치는 그대로다. IDE 티어를 평소대로 설치하면 에이전트가 선택기에 나타나고, 훅이 트리거에 실행되며, steering/스킬이 두 뷰에서 동일하게 로드된다. 에이전트와 `mcp.json`은 핫 리로드(CLI 2.10+/IDE 1.0)되므로 설치기를 다시 실행해도 세션 맥락을 잃지 않는다.
