# 도메인 플레이북

자주 나오는 분석 상황의 표준 접근. 각 플레이북은 "먼저 정의할 것 → 무엇을 볼지 →
함정" 순. 구현은 `python-data-analysis`, 인과 주장은 `experiment-design.md`.

## 이탈 (Churn)

- **먼저 정의**: 이탈이 무엇인가? 구독 취소(명시적) vs N일 미활동(암묵적). 정의가
  숫자를 통째로 바꾼다. 관찰 윈도·이탈 판정 시점 고정.
- **본다**: 코호트별 생존곡선(Kaplan-Meier), 이탈률의 시간 추이, 이탈 **선행지표**
  (이탈 전 활동 급감·지원 티켓 증가 등).
- **함정**: 생존편향(아직 남은 사용자만 보면 이탈 과소평가). 신규/기존 코호트 섞기.

## 코호트 (Cohort)

- **먼저 정의**: 코호트 기준(가입 월? 첫 구매? 획득 채널?). 관찰 지표(리텐션? 매출?).
- **본다**: 코호트×기간 삼각행렬(리텐션 커브). 코호트가 나아지나 나빠지나(제품 개선 신호).
- **함정**: 코호트 크기가 작으면 노이즈. 최근 코호트는 관찰 기간 짧음(미완성 데이터).

## 퍼널 (Funnel)

- **먼저 정의**: 단계와 순서. 시간 윈도(한 세션 내? 7일 내?). 단계 건너뛰기 허용?
- **본다**: 단계별 전환율, 최대 이탈 단계(개선 우선순위), 세그먼트별 퍼널 비교.
- **함정**: 비순차 사용자를 강제로 순차 처리하면 왜곡. 여러 진입점을 한 퍼널로 뭉치기.

## 이상 탐지 (Anomaly)

- **먼저 정의**: "정상"의 기준선. 계절성(요일·월)·추세를 분리(STL 분해)한 뒤 잔차에서 탐지.
- **본다**: 기준선 대비 편차, 지속성(일시적 스파이크 vs 지속 이탈), 연관 지표 동반 변화.
- **함정**: 계절성을 이상으로 오인(주말 하락은 정상일 수 있음). 임계값 하나로 모든 계열 판정.

## 원인 규명 — "왜 늘었/줄었지"

- **기여도 분해**: 총변화 = 물량효과 + 단가효과 + 믹스효과(세그먼트 구성 변화).
  각 요인이 얼마나 기여했는지 수치화 → 어디를 파고들지 결정.
- **드릴다운**: 전체 → 세그먼트(지역·채널·상품)로 쪼개 변화가 집중된 곳 찾기.
- **함정**: 한 요인에 성급히 귀인. 상관 지표를 원인으로 단정(→ 인과는 실험/준실험).
  Simpson's paradox — 전체는 늘었는데 모든 세그먼트는 줄었을 수 있다(믹스 변화).

## 세그먼테이션 (Segmentation)

- **먼저 정의**: 세그먼트 목적(마케팅 타겟? 제품 개인화?). 행동 기반 vs 인구통계 기반.
- **본다**: 세그먼트 간 유의미한 차이가 있나(그냥 나누기 위한 나누기 X). 안정성(시간에
  따라 세그먼트가 유지되나).
- **함정**: 과다 세분화(액션 불가능한 수십 개 세그먼트). 사후 세그먼트로 p-hacking.

## 공통 원칙
- 모든 플레이북은 **"정의 먼저"**. 이탈·정상·코호트의 정의가 결론을 좌우한다.
- 지표는 **분포로** 본다(평균 하나로 판단 금지).
- 반복되는 분석은 재현 가능한 파이프라인으로(`python-data-analysis` 재현성 규약).
