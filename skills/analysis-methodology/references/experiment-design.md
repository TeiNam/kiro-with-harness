# 실험·인과 설계

"X 가 Y 를 일으켰나"에 답하는 법. 관측 데이터의 상관은 인과가 아니다 — 인과를
주장하려면 실험이거나, 성립 가정을 명시한 준실험이어야 한다.

## 인과 사다리 (강한 것 → 약한 것)

1. **무작위 대조 실험(A/B)** — gold standard. 무작위 배정이 교란변수를 평균적으로 제거.
2. **준실험(natural experiment)** — 무작위는 아니지만 준-무작위 상황 이용(DiD·RD).
3. **관측 + 보정** — 성향점수매칭·회귀 보정. 측정된 교란만 통제(미측정 교란은 못 잡음).
4. **순수 관측 상관** — 인과 주장 불가. 가설 생성용.

## A/B 테스트

**설계 순서 (분석 전에 다 정한다):**
1. 가설과 **1차 지표(primary metric)** 하나. 여러 지표를 primary 로 두면 p-hacking.
2. **검정력 분석으로 표본 크기**: 탐지하려는 최소 효과크기(MDE)·유의수준(α=0.05)·
   검정력(1-β=0.8)에서 필요 n 산출. 작으면 진짜 효과도 못 잡는다.
3. 무작위 배정 단위(사용자? 세션?). 오염(spillover) 없게.
4. **실행 기간 고정** — 유의할 때까지 훔쳐보고 멈추면(peeking) 위양성. 순차검정 쓸 거면
   미리 설계.

**해석:**
- 신뢰구간을 본다(점추정만 X). CI 가 0 을 포함하면 효과 불확실.
- **novelty/primacy 효과**: 초반 반응은 신기함일 수 있다. 충분한 기간.
- 세그먼트별 이질적 효과(HTE)는 사후 탐색 — 미리 계획 안 했으면 가설로만.
- 다중 지표·다중 세그먼트를 봤으면 다중비교 보정.

**흔한 오류:**
- SRM(Sample Ratio Mismatch): 50/50 배정인데 실제 비율이 어긋나면 배정 버그. 먼저 확인.
- 생존자만 분석(중도 이탈 무시) → 편향.

## 준실험 (무작위가 불가능할 때)

| 방법 | 언제 | 핵심 가정 (깨지면 무효) |
|------|------|------------------------|
| **DiD (이중차분)** | 처치군·대조군의 처치 전후 비교 | **평행추세**: 처치 없었다면 두 군이 같은 추세였을 것 |
| **회귀불연속(RD)** | 임계값 기준으로 처치 갈릴 때(점수 커트라인) | 임계값 근처에서 다른 요인 불연속 없음 |
| **성향점수매칭(PSM)** | 관측 특성으로 유사 대조군 매칭 | **미측정 교란 없음**(강한 가정 — 대개 못 지킴) |
| **도구변수(IV)** | 처치에만 영향, 결과엔 직접 영향 없는 변수 | 배제 제약(exclusion) — 검증 어려움 |

- 각 방법은 **가정을 명시하고 검증**해야 한다(DiD 는 처치 전 평행추세 플롯).
- 가정이 의심스러우면 결론에 "이 가정 하에서"를 붙인다.

## 관측 분석의 정직함
- 인과를 못 밝히면 밝히지 않는다. "A 와 B 가 상관, 인과 방향은 실험 필요"가 정직한 결론.
- 교란변수 후보를 나열하고, 통제한 것/못 한 것을 구분해 전달.
- "상관관계를 인과로 파는" 것이 분석에서 가장 흔하고 비싼 실수.
